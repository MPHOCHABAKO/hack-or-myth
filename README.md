
# HACK OR MYTH – Android Quiz App

## Overview

**HACK OR MYTH** is a Kotlin-based Android flashcard and quiz application designed to test users’ knowledge of common life hacks and urban myths.

The app presents users with statements, and they must decide whether each statement is a real life hack (**Hack / True**) or an urban myth (**Myth / False**).

---

## Features

### Welcome Screen

* Displays app branding and logo
* Brief description of the app
* Start button to begin the quiz

### Quiz Screen

* Displays one statement at a time
* Two answer buttons:

  * **HACK (True)**
  * **MYTH (False)**
* Immediate feedback after each answer:

  * E.g Correct: “That’s a real time saver!”
E.g Incorrect: “That’s just an urban myth!”
* Next button to proceed through questions
* Score tracking system

### Score Screen

* Displays total correct answers
* Personalized feedback based on score:

  * Master Hacker
  * Sharp Thinker
  * Stay Safe Online
* Review button to revisit all questions and explanations
* Restart option to replay the quiz

### Review Screen

* Lists all statements
* Shows correct answers
* Provides educational explanations for each statement
